Hard C vs Soft C

Seret setiap kata ke keranjang yang tepat — atau ketuk kata, lalu ketuk keranjangnya. Ketuk dua kali pada kata untuk mendengar pengucapannya 🔊

⭐ Skor: 0 ❌ Salah: 0 📦 Sisa: 0

🧊 Hard C

bunyi /k/ seperti cat

🎬 Soft C

bunyi /s/ seperti city
Aturan mudah:
Jika huruf C diikuti e, i, atau y → biasanya Soft C (bunyi /s/): cent, city, cycle, juice.
Jika huruf C diikuti a, o, u atau huruf mati → biasanya Hard C (bunyi /k/): cave, cold, cut, crab.
